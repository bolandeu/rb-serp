
 Usage: serp search [OPTIONS] {queries}...

 Позиции в выдаче Yandex/Google: позиция, домен, URL, заголовок.

 Запросы выполняются по очереди; для каждой страницы провайдеры пробуются
 по порядку из --provider, пока один не ответит. Отказали все → ошибка
 PROVIDER_ERROR (exit 5) или AUTH_REQUIRED (exit 3). Пустая выдача без
 сбоя — не ошибка. Ровно --top позиций, дубли между страницами убраны.

 Ответ провайдера целиком (с рекламой, похожими запросами и т.д.) всегда
 пишется в журнал; другие блоки отдают команды snippets, ads, related,
 summary — с --cache они берут уже полученный ответ бесплатно.

 --json: {"ok": true, "count": N, "results": [{serp_position, query,
 searchengine, url, domain, title}, ...], "sources": [{query, engine,
 page, provider, fetched_at, from_cache, complete, billable_requests,
 cost, cost_currency, cost_source}, ...], "billable_requests_total": N,
 "cost_total": X} (+ "saved_to" при --output). complete=false —
 провайдер отдал неполную страницу (повтор и следующий провайдер не
 помогли); из журнала такая не отдаётся.

 Стоимость — за каждый платный ответ провайдера. billable_requests —
 сколько их ушло на страницу: каждый успешный ответ, в том числе
 неполный (повтор неполной страницы — 2), ответ, после которого ушли на
 следующий провайдер, и «нет результатов»; сбои сети и ответы-ошибки
 провайдера (их повторы) не считаются. cost — рубли за страницу
 (cost_currency "RUB"): сумма billable_requests × цена по каждому
 провайдеру; cost_total и billable_requests_total — по всем страницам.
 Цена за запрос — по провайдеру: env SERP_<PROVIDER>_PRICE (например
 SERP_XMLRIVER_PRICE=0.25; сервер и Windmill передают только его)
 перекрывает [prices] в .serp/config.toml (xmlriver = 0.25); не число —
 INVALID_ARGUMENTS. cost_source — откуда cost: "provider" — фактическая
 из ответа провайдера (XML River и XMLStock её не отдают),
 "price_table" — цена × billable_requests, "cache" — из журнала
 (from_cache=true, billable_requests 0, cost 0), null — у оплаченного
 провайдера нет цены (cost и cost_total null, предупреждение в stderr,
 не ошибка). Те же поля стоимости отдают snippets, ads, related, summary.
 --format table печатает таблицу в stderr по мере готовности запросов;
 csv/domains/domains-se печатают данные в stdout.


 Example: serp search "python разработка"
          serp search "seo" "продвижение" --engine both --top 20
          serp search "такси" --yandex-lr 2 --format domains
          serp search "ремонт" -e google --google-loc 1012153
          serp search "запрос" -e both -p xmlstock,xmlriver   # xmlriver — фолбэк
          serp search "запрос" --cache --max-age 7d          # из журнала, если свежее недели
          serp search "запрос" --json --output results.csv

│                                                       https://yandex.ru/dev/xml/doc/ru/referenc… │

│                                                       1011969=Москва; 1012153=СПб. Все коды:     │
│                                                       https://xmlriver.com/files/geo.csv         │
│ --provider    -p      <str>                           Очередь провайдеров через запятую: первый  │

│                                                       xmlriver (XML River — yandex и google);    │
│                                                       xmlstock (XMLStock — yandex и google). По  │
│                                                       умолчанию — `providers` из конфига         │
│                                                       проекта, иначе xmlriver.                   │
│ --cache                                               Взять ответ из журнала, если такой запрос  │
│                                                       (поисковик, регион, текст, страница) уже   │
│                                                       был — бесплатно. Только полные ответы      │
│                                                       провайдеров из --provider, в порядке       │
│                                                       очереди: ответ XMLStock не выдаётся за     │
│                                                       ответ XML River. Без флага — всегда живой  │
│                                                       запрос. Ответы пишутся в журнал всегда.    │
│ --max-age             <str>                           С --cache: брать из журнала, только если   │
