
 Usage: serp init [OPTIONS]

 Создать проект в папке: .serp/config.toml с очередью провайдеров и min_version.

 Example: serp init --non-interactive

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --name           <str>  Имя проекта (по умолчанию — имя папки).                                  │
│ --force                 Перезаписать настройки уже созданного проекта.                           │
│ --json                  Машиночитаемый вывод: JSON в stdout.                                     │
│ --quiet                 Не печатать ничего, кроме данных.                                        │
│ --verbose               Подробная диагностика в stderr.                                          │
│ --help                  Show this message and exit.                                              │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
