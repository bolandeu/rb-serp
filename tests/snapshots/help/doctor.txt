
 Usage: serp doctor [OPTIONS]

 Диагностика: версия, проект, настройки, база, связка ключей, доступы провайдеров.

 Всегда завершается с кодом 0 — результат это сам отчёт; `healthy`
 говорит, прошли ли все проверки.

 Example: serp doctor --json

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --json             Машиночитаемый вывод: JSON в stdout.                                          │
│ --quiet            Не печатать ничего, кроме данных.                                             │
│ --verbose          Подробная диагностика в stderr.                                               │
│ --help             Show this message and exit.                                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
