
 Usage: serp cache info [OPTIONS]

 Размер журнала, число записей, самая старая и новая, разбивка по провайдерам.

 Example: serp cache info --json

│ --json           Машиночитаемый вывод: JSON в stdout.                                            │
│ --quiet          Не печатать ничего, кроме данных.                                               │
│ --help           Show this message and exit.                                                     │
