
 Usage: serp cache clear [OPTIONS]

 Удалить записи журнала: старше срока (--older-than) или все (--all).

 Вместе с ответами удаляются их позиции (представление serp_v1_results).

 Необратимо: сначала --dry-run (покажет, сколько удалится), затем
 --confirm (обязателен вместе с --non-interactive).

 --json: {"ok": true, "deleted": N} (при --dry-run — {"dry_run": true,
 "would_delete": N}).

 Example: serp cache clear --older-than 30d --dry-run

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --older-than             <str>  Удалить записи старше срока: 30m, 12h, 7d, 2w.                   │
│ --all                           Удалить весь журнал.                                             │
│ --dry-run                       Показать, что будет сделано, ничего не меняя.                    │
│ --confirm                       Подтвердить необратимое действие (обязательно вместе с           │
│                                 --non-interactive).                                              │
│ --non-interactive               Никогда не спрашивать; при нехватке данных — ошибка.             │
│ --json                          Машиночитаемый вывод: JSON в stdout.                             │
│ --quiet                         Не печатать ничего, кроме данных.                                │
│ --help                          Show this message and exit.                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
