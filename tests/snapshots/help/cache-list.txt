
 Usage: serp cache list [OPTIONS]

 Последние записи журнала (без самих ответов), свежие первыми.

 --json: {"ok": true, "count": N, "results": [{id, fetched_at, provider,
 engine, region, query, page, complete, size}, ...]}; size — сжатый размер
 ответа, complete=false — неполная страница (из кэша не отдаётся).

 Example: serp cache list -q диван

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --query  -q      <str>               Только записи, где запрос содержит этот текст.              │
│ --limit  -n      <int range> [x>=1]  Сколько последних записей показать. [по умолчанию: 50]      │
│ --json                               Машиночитаемый вывод: JSON в stdout.                        │
│ --quiet                              Не печатать ничего, кроме данных.                           │
│ --help                               Show this message and exit.                                 │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
